# Telos

A sleek, developer-focused Chrome New Tab extension featuring a clean terminal aesthetic and customizable features.

## Features

- **Terminal Aesthetic**: Minimalist, monospace-driven design.
- **Customizable Themes**: Multiple curated dark modes (Ash, Midnight, Abyss, Forest, Plum, Ember, Slate, Ocean).
- **Productivity Panels**:
  - `todo --list`: A quick to-do list for managing tasks.
  - `~/shortcuts`: Draggable shortcut links to your favorite sites.
  - `// sticky-notes`: A simple scratchpad for quick notes.
- **Customization**: Name your tab whatever you want directly in the settings.
- **Lightweight**: Pure Vanilla HTML, CSS, and JavaScript with zero external dependencies.

## Installation

You can install Telos directly from the Chrome Web Store:
[**Add Telos to Chrome**](https://chromewebstore.google.com/detail/telos/dlddlcfpmhfoddfapagfpglkconkhbdg)

## Settings

Click the settings icon (`//`) in the top right corner of the new tab page to:
- Change the tab name.
- Select your background theme.
- Toggle individual productivity panels on or off.
